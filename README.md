# ai-programming-week11
# 성적 CSV 처리 및 AI 테스트 실험

## 무엇을 하나요? (What)

성적 CSV 파일을 읽어 유효한 이름과 점수를 모으고,
유효하지 않은 행은 건너뛴 이유와 함께 기록합니다.

이번 실습에서는 AI에게 코드를 제공한 경우와 명세를 제공한 경우의
테스트 결과를 비교하고, 버그가 있는 함수에 대한 함정 실험도 진행했습니다.

## 왜 만들었나요? (Why)

성적 CSV 파일에는 이름이나 점수가 비어 있거나, 점수가 정수가 아니거나
0~100 범위를 벗어난 행이 있을 수 있습니다. 이런 데이터를 읽을 때
유효한 성적과 문제가 있는 행을 구분하고, 어떤 이유로 건너뛰었는지
확인할 수 있도록 이 프로그램을 사용했습니다.

또한 AI에게 코드와 명세를 각각 제공했을 때 작성되는 테스트를 비교하고,
버그가 있는 함수를 테스트가 찾아낼 수 있는지 확인하기 위해
이번 실험을 진행했습니다.

## 어떻게 실행하나요? (How)

### 준비

- Python이 설치되어 있어야 합니다.
- 저장소를 GitHub Desktop으로 내려받은 뒤, 저장소 폴더에서
  PowerShell 또는 VS Code 터미널을 엽니다.
- 프로그램을 실행할 때 사용할 CSV 파일이 필요합니다.

### 프로그램 실행

저장소 폴더에 `scores.csv`가 있는 경우 다음 명령으로 실행합니다.

```powershell
python load_scores.py scores.csv
```

프로그램은 유효하게 읽은 이름과 점수를 출력하고,
건너뛴 행이 있다면 행 번호와 이유를 출력합니다.

## 어떻게 테스트하나요?

### 테스트 도구 설치

```powershell
python -m pip install pytest pytest-cov
```

### A 테스트: 코드를 제공한 경우

```powershell
python -m pytest test_ai_A.py -v
```

커버리지 측정:

```powershell
python -m pytest test_ai_A.py --cov=load_scores --cov-report=term-missing
```

- 실행 결과: **38개 통과**
- 커버리지: **80%**
- 실행되지 않은 줄: **77~86행**
- 실행 조건: AI가 작성한 원본 import는 `score_loader`였으나,
  실제 파일명에 맞게 `load_scores`로 수정한 뒤 실행했습니다.

### B 테스트: 명세를 제공한 경우

```powershell
python -m pytest test_ai_B.py -v
```

커버리지 측정:

```powershell
python -m pytest test_ai_B.py --cov=load_scores --cov-report=term-missing
```

- 실행 결과: **10개 통과, 33개 실패**
- 커버리지: **80%**
- 실행되지 않은 줄: **77~86행**
- AI가 받은 명세를 바탕으로 작성한 테스트와 프로그램의 동작에
  소수 점수, 헤더 검사, 건너뛴 행의 기록 형식 등의 차이가 있었습니다.
- AI가 작성한 원본 import는 `scores`였습니다.

### 함정 실험: 버그가 있는 `find_max`

실행용 복사본에서 `find_max` 테스트만 선택해 실행했습니다.

```powershell
python -m pytest test_ai_bug_run.py -v -k find_max
```

- 실행 결과: **8개 통과, 3개 실패**
- 실행 조건: AI 테스트 원본은 보관하고, 실행용 복사본에서
  import를 `bug3_logic`에 맞게 변경했습니다.
- AI는 `find_max([70, 85, 60, 95])`의 기대값을 `95`로 작성했습니다.
- 함정 함수는 마지막 값을 검사하지 않아 `85`를 반환했고,
  해당 테스트의 실패를 통해 버그가 드러났습니다.

### A와 B 비교

| 항목 | A: 코드 제공 | B: 명세 제공 |
|---|---:|---:|
| 테스트 함수 수 | 25개 | 17개 |
| 실행 케이스 수 | 38개 | 43개 |
| 통과 | 38개 | 10개 |
| 실패 | 0개 | 33개 |
| 커버리지 | 80% | 80% |

커버리지는 코드의 실행 범위를 나타내므로,
커버리지가 같아도 테스트의 기대값과 통과 결과는 다를 수 있습니다.
B 테스트와 프로그램 중 어느 쪽이 명세에 맞는지는
10주차 명세서와 대조해야 합니다.

## 파일 구성

- `load_scores.py`: 성적 CSV를 읽고 유효한 행과 건너뛴 행을 반환합니다.
- `test_ai_A.py`: 프로그램 코드를 제공해 AI에게 받은 테스트입니다.
  실행을 위해 import를 수정했습니다.
- `test_ai_B.py`: 명세를 제공해 AI에게 받은 테스트입니다.
- `test_ai_bug.py`: 버그가 있는 함수에 대해 AI에게 받은 테스트 원본입니다.
- `bug3_logic.py`: 함정 실험에 사용한 버그가 있는 함수입니다.
- `scores.csv`: 프로그램 실행에 사용하는 성적 CSV 파일입니다.
- `README.md`: 프로그램과 실험의 실행 방법 및 결과를 설명합니다.
- `LICENSE`: 저장소의 라이선스 내용입니다.
